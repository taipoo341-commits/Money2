# 加班費計算系統：Money3 v43 更新說明

正式入口為 `https://taipoo341-commits.github.io/Money3/`，主程式使用根目錄的 `index.html`。`Money3-main/` 是此次比較的舊版參考資料；`可刪除/` 存放備份及驗證資料，兩個資料夾都不要上傳至正式網站。

## PWA 修正

- 使用實體 `manifest.json?v=43`，保留 192、512 像素一般 PNG 圖示，使用獨立的 maskable 圖示。圖示移除灰色方形底與深色外圈，保留金色標誌；maskable 圖示使用完全不透明背景及安全區留白。啟動背景色設為與 maskable 圖示底色相同的 `#091A2E`。Android 最終裁切外形與啟動畫面的實際呈現依裝置而異，不能由網頁強制指定。
- Manifest ID 固定為 `/Money3/`，與 2026-10-04 查到的線上 Money3 相同；啟動網址 `./index.html`、範圍 `./`。此版本應部署於 `/Money3/`。先前本機的 `id: "./"` 與目前線上識別不同，其他路徑或其他 ID 的既有安裝不保證會自動更新。
- 收到 Chrome 真正的 `beforeinstallprompt` 事件後才顯示安裝列；已安裝的獨立視窗不顯示。關閉只記錄於本次分頁工作階段，不清除使用者資料。
- Worker 以 `updateViaCache: "none"` 註冊。必要素材全部預快取成功才啟用新版，缺檔時保留舊 Worker。
- 快取名稱依部署路徑隔離；Money3 為 `personal-overtime-app-%2FMoney3%2F-v43`。前綴避開舊版的 `personal-overtime-shell-`，並只清理本站的新前綴，保留舊共用快取及其他網站快取。
- Manifest 與安裝圖示線上優先，離線使用同一個不含查詢參數的素材快取。首頁兩種入口及停班停課 JSON 也維持離線備援。

2026-10-04 查核時，線上 Money3 的必要素材皆回傳 200；Money2 的兩張 maskable 圖示回傳 404，會導致該版 Worker 的必要預快取失敗。此事與過去 v40 的 JPG 404 是不同快照，不能把它們當成目前 Money3 的安裝失敗原因。桌面安裝檢查、安裝列事件及實體 Android 的 WebAPK 安裝是不同驗收項目。

## 本次 v43 修正

- 清除按鈕改為「清除本月」「清除本年」；摘要兩項改為「加班：」「假日：」。
- 年度上限驗證會還原每日紀錄副本，時數儲存改在驗證完成後重新取得當日紀錄，避免半小時及整數時數選取後遺失；保留年度上限、期限資格與月份切換防護。
- 移除手機假別視窗新增的單日編輯區塊，恢復 Money3-main 的假別選單標題與內容。每日時數和 RESET 直接在主月曆操作；保留最愛、自訂及複合假別。
- 考勤年度三張已休卡片在手機將天數、小時分行，桌面維持同一行；其餘年度架構、結算與公式維持原有行為。
- 一般與 maskable 圖示各提供 192／512 像素；新版背景不再包含灰底方框與深色外框。既有 Android 安裝的圖示更新需實機確認，不需清除網站資料。

## 保留的介面行為

- 手機與桌面主月曆恢復 Money3-main 的日期格操作：假別、時數及 RESET 直接顯示；保留日期／月份切換防護及請假限制。
- 停止辦公日的主月曆縮寫改為「停辦公」。
- 加給試算旁只列加班、假日出勤，入口改為「查看細項」。其他細項在明細視窗查詢，合計仍包括所有加給項目。
- 年度請假資訊保留現有架構；三個結算標籤維持「上年度未休 天/時」、「本年度未休 天/時」、「不休假獎金折算」。
- 加給明細關閉按鈕移至底部固定操作列，明細內容可捲動，底部保留手機安全區空間。

Money3-main 的 16 個參考檔案雜湊未變更。桌面 Chrome 的 Manifest 與可安裝性檢查沒有回報錯誤；此結果不能代替實體 Android 的安裝、圖示更新及啟動畫面驗收。詳細紀錄及畫面保存在 `可刪除/施工_v43_20261004/`。

## 部署後驗收

1. 確認 `/Money3/manifest.json?v=43`、`/Money3/sw.js` 與 manifest 所列圖示皆可正常讀取；Chrome 重新載入後確認新版 Worker 啟用。
2. 手機 Chrome 收到可安裝事件時會顯示安裝列；也測試 Chrome 選單的「安裝並建立捷徑」。安裝完成後從桌面圖示開啟，確認獨立視窗及離線功能。未出現提示不等於原生安裝一定失敗，需一併記錄 Chrome 選單結果。
3. 請假與時數修改後重新載入，確認紀錄和年度餘額保留；檢查不同月份不互相覆蓋。
4. 檢查手機與桌面月曆直接操作、假別選單內容、試算旁兩項金額及明細底部關閉按鈕。
5. 在家庭照顧假與身心調適假分別選 0.5、1.5、7.5HR，重新載入確認保存；年度不足時仍必須拒絕超額設定。
6. 手機檢查三張年度卡片的混合天數與時數不重疊，從桌面開啟 App 檢查圖示及啟動畫面。

不需清除 localStorage 或 IndexedDB。不要用清除網站資料作為例行更新步驟，以免刪除已輸入的排班、請假與薪給紀錄。
